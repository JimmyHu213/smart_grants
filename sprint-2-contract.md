# Sprint 2 Contract: Pipeline — Companies, Applications, User Dashboard

- [ ] Admin can create a company with all profile fields
- [ ] Admin can create a user account (email + password) linked to a company
- [ ] Admin can view all companies and their users at /admin/companies
- [ ] Admin can edit company details
- [ ] Admin can assign a grant to a company's pipeline
- [ ] Admin can change application status through all workflow stages
- [ ] Status transitions are validated (no arbitrary backwards movement)
- [ ] Pipeline view at /admin/pipeline shows all applications with filtering
- [ ] Application cards show grant name, company, status, deadline, checklist progress
- [ ] Admin can edit application notes
- [ ] User dashboard at /dashboard shows only their company's applications
- [ ] User sees grant name, status, deadline, and checklist progress per application
- [ ] User cannot access other companies' data
- [ ] All server actions have Zod input validation
- [ ] Environment variables are validated (no ! assertions)
- [ ] Accessibility issues from Sprint 1 evaluation are fixed
- [ ] Code follows Australian English conventions
- [ ] All code compiles without TypeScript errors
